# User Guide

## Citizen

1. Open the portal and choose **Submit a Grievance**.
2. Register or sign in.
3. Select the district and category.
4. Enter a subject and detailed description.
5. Optionally attach a supporting file.
6. Submit and save the generated reference number.
7. Use **Track Grievance** to view status and public history.
8. After resolution, open the feedback form in the dashboard and submit a rating.

## CMO administrator

1. Sign in using the CMO administrator account.
2. Review totals for submitted, under-review, in-progress, resolved and overdue grievances.
3. Filter the grievance table by district, category, priority or status.
4. Click **Analyze** to request an advisory AI summary and classification.
5. Review the grievance details and attachments.
6. Make the official decision and assign the appropriate department/officer.
7. Monitor the action-taken report.
8. Accept or reject the report and update the grievance status.

AI recommendations must be treated as suggestions, not automatic decisions.

## Department officer

1. Sign in using the assigned officer account.
2. Review grievances forwarded to your department.
3. Open a grievance and inspect its history and attachments.
4. Update status and add investigation remarks.
5. Submit an action-taken report for CMO review.

## Demonstration accounts

The default fictional accounts are documented in the root README. Passwords should be changed or replaced for any deployed demonstration environment.
