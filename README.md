# CM Kerala Grievance Portal

Recruitment prototype for a Chief Minister's public grievance redressal portal. This is not an official Government of Kerala service.

## Demo accounts

These accounts are fictional and exist only for evaluation. Create them locally with `npm run seed:staff` from the `backend` folder. Citizens register themselves on the public portal.

| Role | Email | Password |
|---|---|---|
| CMO administrator | cmo.admin@grievance.test | DemoCmo#2026 |
| Department officer | pwd.officer@grievance.test | DemoOfficer#2026 |

The officer account belongs to the fictional Public Works Department. Staff passwords live in the local `.env` file and are not committed.
